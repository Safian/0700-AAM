## Akai MPC Key 61
- `akai_mpc_hardware/README.md` – knowledge base entry point (official manuals, sources, checksums).
- `akai_mpc_hardware/KEY61_HW_BEHAVIOUR.md` – measured hardware behaviour (ports, channels, LEDs, SysEx, boot). Append every new fact.
- `akai_mpc_hardware/KEY61_USB_AND_PHONE.md` – Controller Mode and phone/tablet use (manual and web research, unverified on hardware).
- `akai_mpc_hardware/KEY61_LED_COLOURS.md`, `KEY61_TOUCH_STRIP_MODES.md`, `KEY61_DOC_VS_KICK.md` – LEDs, touch strip, manual vs Kick.
- `akai_mpc_hardware/tools/` – `build_arm.sh`, `deploy_mpc.sh`, `mpcsnoop.c`; `captures/` – recorded raw MIDI.
- `akai_mpc_hardware/walkthrough/`, `WALKTHROUGH_PLAN.md` – manual walkthrough work packages and claims registers.
- `AKAI_MPC_KEY61_BUILD_RECIPE.md` – ARMv7 build recipe. `AKAI_MPC_KEY61_HW_TEST_*.md`, `_TODO.md`, `_REVIEW_ROUND*.md`, `_HARDWARE_REVIEW.md`, `_MORNING_DECISIONS.md` – earlier test, review and planning notes (flat files, not moved).
- `akai_mpc_key61/`, `hw-mailbox/` – earlier artefacts and the cloud-session mailbox.
