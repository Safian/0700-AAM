Type and spacing

Sans: Myriad Pro (Kick theme font) then system UI fonts. Labels 10-11 px caps +0.08em, body 12-14 px, values mono 11-13 px.
Grid: 4 px base; panel padding 8/12, gap 8 (12 at ≥1100 px). Controls 28-32 px high, knob 40-62 px.
Accent rule: amber = value / active / selected; cyan = bipolar value, MIDI, focus; red only for clip/error.
